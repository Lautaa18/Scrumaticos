Kanban en detalle

Kanban es un método para gestionar el flujo de trabajo: se visualizan las tareas en un tablero, se limita el trabajo en curso (WIP) y se mejora el proceso de forma continua.

Cómo funciona

Visualizar el trabajo

Cada tarea es una tarjeta y cada columna, un estado del proceso.

Limitar el WIP

Cada columna admite un máximo de tarjetas. Si está llena, primero se termina algo.

Gestionar el flujo

Se mide cuánto tarda una tarea (lead time) y cuántas se terminan (throughput).

Mejorar continuamente

No hay iteraciones fijas: el proceso se ajusta a medida que se observan cuellos de botella.

Probá el tablero

Arrastrá las tarjetas entre columnas, con el mouse o con el dedo, o usá las flechas de cada tarjeta. La columna En proceso tiene un límite WIP de 2.
