Gestión de la calidad del software

Herramientas de calidad

Una introducción a las herramientas que usan los equipos para seguir defectos, revisar el código y gestionar las pruebas. Filtrá por categoría.

Catálogo

Bug Trackers

Jira

Gestiona incidencias y tareas con flujos configurables; muy usado en equipos Scrum.

Bug Trackers

GitHub Issues

Registro de defectos integrado al repositorio, con etiquetas y vínculo a commits.

Bug Trackers

Bugzilla

Herramienta libre de seguimiento de defectos creada por Mozilla.

Linters

ESLint

Analiza JavaScript y avisa errores y malas prácticas antes de ejecutar el código.

Linters

Stylelint

Revisa hojas de estilo CSS: propiedades inválidas, duplicados y orden.

Linters

Pylint

Linter para Python que mide estilo y posibles errores.

Test Management

TestRail

Organiza casos de prueba, planes y ejecuciones con reportes de avance.

Test Management

Zephyr

Gestión de pruebas integrada a Jira para trazar casos con historias.

Test Management

Testlink

Herramienta libre para redactar casos de prueba y registrar resultados.

Análisis de calidad

SonarQube

Mide calidad del código: bugs, vulnerabilidades, duplicación y cobertura.

Análisis de calidad

Lighthouse

Audita páginas web: rendimiento, accesibilidad y buenas prácticas.

Análisis de calidad

Playwright

Automatiza pruebas en navegadores reales; la usamos para la regresión del sitio.
